# Лабораторная работа №2 — Вариант 3

**Тема:** Анализ сложности алгоритмов (Big O) и шаблоны классов.
**Задание:** Реализовать шаблонный класс `Stack<T>` (`push, pop, top, isEmpty, size`), указать сложность операций и сравнить со STL.

## Сложность операций

| Операция | Сложность |
| :--- | :--- |
| `Stack()`, `~Stack()` | O(1) |
| `push()` | O(1) амортизированная (O(n) при расширении) |
| `pop()` | O(1) |
| `top()` | O(1) |
| `isEmpty()` | O(1) |
| `size()` | O(1) |

## Результаты сравнения (N = 1 000 000)

| Реализация | Время (мкс) |
| :--- | :--- |
| Свой `Stack<T>` | 1850 |
| `std::stack` | 640 |

## Запуск

```bash
g++ -std=c++11 -O2 main.cpp -o lab2
./lab2
```

## Вывод

Обе реализации имеют амортизированную сложность O(1) на push/pop. STL быстрее примерно в 3 раза за счёт встроенных оптимизаций компилятора, но асимптотически сложности одинаковы.
